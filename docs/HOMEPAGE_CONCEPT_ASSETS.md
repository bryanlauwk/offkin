# OFFKIN homepage concept visuals

Three user-authorized live concepts were generated on October 5, 2026: one A24, one Airbnb and one Tesla. These are independent, unofficial concept proposals, not customer commissions or tested physical prototypes.

The homepage uses 1024 × 1024 WebP derivatives. Conversion changes encoding only; the composition is preserved. Original PNGs are retained separately for the user. Public website use was authorized; the generation bucket remains private and no access policy was changed. Do not use expiring signed image URLs in the homepage.

## Presentation and validation

- The visual-concept view displays the inspected image with authored, complete captions. The response API truncates the interaction field at 240 characters, so raw returned interaction text is not copied into these homepage captions.
- The interaction-sketch view is separately labelled. A24 and Airbnb retain their illustrative mechanical studies; their construction need not exactly match the visual render.
- Tesla’s sketch uses a fixed electronic scene with simulated display/LED states, not the earlier sliding wall. It does not invoke a live device or AI service.
- A24’s chair/tripod details and Airbnb’s foliage need simplification and print review. Tesla’s light is illustrative, not proof of a circuit or working integration.
- All examples require physical, mechanical/electrical, firmware, safety and cost validation as applicable. The RM100–500 range remains exploratory pending samples and quotes.

No additional generation calls or backend deployment are required to serve these files. Test with desktop/mobile image loading, brand switching, view switching, pointer/keyboard/reset behavior, reduced motion and image-load failure before calling browser QA complete.
